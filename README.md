# Космокот

Синий инопланетный котик с крылышками и рожками, который живёт внизу экрана Windows: гуляет, спит, играет с клубком, ловит бабочек и напоминает о задачах из Notion.

## Как запустить

1. Распакуйте архив в любую папку, например `Документы\Космокот`.
2. Дважды щёлкните `AlienCat.exe`.
3. Если Windows покажет «Windows защитил ваш компьютер», нажмите **Подробнее** → **Выполнить в любом случае**. Так Windows реагирует на любые программы без платной цифровой подписи.

Котик появится над панелью задач, а его значок — возле часов. Через этот значок открываются меню и настройки.

## Как подключить Notion (один раз)

1. Откройте [notion.so/profile/integrations](https://www.notion.so/profile/integrations) и нажмите **Новая интеграция** (New integration).
2. Название — например, «Космокот», рабочее пространство — ваше, тип — **Внутренняя** (Internal). Сохраните.
3. Скопируйте **ключ интеграции** (Internal Integration Secret, начинается с `ntn_`). Никому его не показывайте.
4. Откройте в Notion базу **«Задачи котика»** → **•••** справа вверху → **Подключения** (Connections) → найдите «Космокот» и подтвердите доступ.
5. Скопируйте ссылку на базу: **•••** → **Копировать ссылку** (Copy link).
6. В котике: значок возле часов → **Настройки** → вставьте ключ и ссылку → **Проверить подключение**. Должно появиться «Всё работает!» → **Сохранить**.

## Как пользоваться базой

| Поле | Что значит |
|---|---|
| Название | Что сделать |
| Напомнить | Дата и время напоминания. Если время не указано, котик напомнит в 9:00 |
| Готово | Галочка; котик ставит её сам, когда вы нажимаете «Готово» |
| Приоритет | Обычный / Важный / Срочный. О важных и срочных котик предупредит ещё за 10 минут |
| Повтор | Нет / Каждый день / По будням / Каждую неделю / Каждый месяц. У повторяющейся задачи «Готово» переносит дату на следующий раз |
| Тип | Задача или Заметка. Заметки, добавленные через котика, без даты и без напоминаний |

## Что умеет котик

- **Клик** — мурлычет. **Схватить и перетащить** — болтает лапками, а если отпустить в воздухе, падает и приземляется.
- **Двойной клик** или меню «Добавить заметку» — быстро записать мысль в Notion.
- **Напоминание** — котик держит табличку с задачей: «Готово» или «Отложить» (на 10 минут, на час, до завтра 9:00). Если долго не отвечать, начинает подпрыгивать.
- **Утром** (при первом запуске за день) показывает задачи на сегодня и пропущенные.
- **В полноэкранных играх и видео** прячется и копит напоминания.
- **Без интернета** напоминает по последнему сохранённому списку, а отметки «Готово» отправит позже.

## Настройки

Размер (×1, ×2, ×3), характер (спокойный / обычный / игривый), ловля курсора, тихие часы и запуск вместе с Windows.

## Где хранятся данные

Всё хранится только на вашем компьютере, в папке `%AppData%\AlienCat`:
- `settings.json` — настройки; ключ Notion зашифрован средствами Windows для вашей учётной записи;
- `state.json` и `cache.json` — отложенные напоминания и последний список задач;
- `logs\` — журнал за последние 7 дней. Если что-то пошло не так, пришлите файл за нужный день.

Котик связывается только с `api.notion.com`.

## Как выключить и удалить

Значок возле часов → **Выход**. Чтобы убрать автозапуск, снимите галочку в настройках. Для полного удаления закройте котика, удалите папку с `AlienCat.exe` и папку `%AppData%\AlienCat`.

## Для разработчиков

- `src/AlienCat.Core` — логика (поведение, напоминания, Notion, хранение), тесты в `tests/AlienCat.Core.Tests`.
- `src/AlienCat.App` — WPF-приложение для Windows.
- `tools/art/generate_sprites.py` — рисует все кадры котика (Python + Pillow).
- Сборка и тесты запускаются в GitHub Actions (`.github/workflows/build.yml`); готовый архив — в артефакте **AlienCat**.
