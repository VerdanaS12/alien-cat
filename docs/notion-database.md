# База «Задачи котика»

Создана в Notion пользователя 2026-11-05 через коннектор Notion, приватная страница верхнего уровня.
Ссылка и идентификаторы базы в репозиторий не записываются: пользователь вставляет ссылку в настройки котика.

Поля: Название (title), Напомнить (date), Готово (checkbox), Приоритет (select: Обычный, Важный, Срочный),
Повтор (select: Нет, Каждый день, По будням, Каждую неделю, Каждый месяц), Тип (select: Задача, Заметка).
