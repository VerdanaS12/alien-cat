# Космокот Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Windows desktop pet — a detailed pixel-art blue alien cat with wings and horns — that lives on screen, plays, and reminds the user about tasks from a Notion database.

**Architecture:** All logic (pet brain and motion, reminder rules, recurrence, Notion gateway, sync with offline cache and queue, persistence, logging, animation catalog) lives in a platform-neutral `AlienCat.Core` library tested on Linux with xUnit. `AlienCat.App` is a thin WPF shell: transparent topmost windows that render sprites, a tray icon, dialogs and Win32 calls. Sprites are generated by a Python/Pillow script into PNG sheets plus `animations.json`.

**Tech Stack:** C# / .NET 10 (LTS), WPF + WinForms `NotifyIcon`, `System.Net.Http` + `System.Text.Json`, `System.Security.Cryptography.ProtectedData`, xUnit, Python 3 + Pillow for art.

**Spec:** `docs/superpowers/specs/2026-11-05-alien-cat-design.md`

## Global Constraints

- Target frameworks: `net10.0` (Core, Tests), `net10.0-windows` (App, `UseWPF`, `UseWindowsForms`, `EnableWindowsTargeting=true` so it builds on Linux). If .NET 10 is not the current LTS when executing, use the current LTS and change all three projects together.
- Deliverable: one self-contained, single-file, compressed `AlienCat.exe` for `win-x64`; the user installs nothing.
- All user-facing text (UI, tray, messages, README) in Russian.
- Sprite frame 64×64 px; integer scaling ×1/×2/×3, default ×2, nearest-neighbor, no smoothing.
- Notion field names exactly: `Название` (title), `Напомнить` (date), `Готово` (checkbox), `Приоритет` (select: `Обычный`, `Важный`, `Срочный`), `Повтор` (select: `Нет`, `Каждый день`, `По будням`, `Каждую неделю`, `Каждый месяц`), `Тип` (select: `Задача`, `Заметка`). Empty → `Обычный` / `Нет` / `Задача`.
- Poll Notion every 60 s and at startup; early reminder 10 min before for `Важный`/`Срочный`; nagging after 5 min unanswered; snooze 10 min / 1 h / tomorrow 09:00.
- Night sleepiness 22:00–07:00; quiet hours default off, default range 23:00–08:00.
- Cursor hunt: cursor still ≥ 2 s, within 200 px, cooldown 10 min, toggle in settings. Games (yarn, butterfly, toy mouse) every 10–20 min at «обычный» activity.
- Files in `%AppData%\AlienCat\`: `settings.json`, `state.json`, `cache.json`, `logs\` (daily files, keep 7 days). Notion token stored encrypted with DPAPI (CurrentUser).
- The app talks only to `https://api.notion.com`.
- Commits end with the attribution lines from the session reminder.

## Review Focus

1. **All-day dates in Notion** (`Напомнить` without time): remind at 09:00 local time that day; never at midnight. → Task 3 test `FromPage_DateWithoutTime_Means0900Local`.
2. **Dates with explicit offsets / naive dates**: offset dates keep their instant; naive datetimes are local time. → Task 3 tests `FromPage_DateWithOffset_KeepsInstant`, `FromPage_NaiveDateTime_IsLocal`.
3. **Task completed, rescheduled or deleted in Notion while its reminder is pending**: the reminder disappears after the next poll. → Task 2 test `GetPending_TaskNoLongerListed_NotReturned` plus Task 10 wiring step.
4. **Many tasks already overdue at startup (PC was off)**: they go into the morning list only, not one popup each; only tasks coming due while the app runs pop up. → Task 2 test `GetPending_OverdueBeforeSessionStart_NotPopped`.
5. **Notion pagination and rate limiting** (>100 results, HTTP 429): all pages are read; 429 waits `Retry-After` once, then counts as offline for this poll. → Task 3 tests `Query_FollowsCursorAcrossPages`, `Query_429_RetriesOnceThenRateLimited`.
