# Космокот — трюки и гардероб

Дата: 2026-11-07. Дизайн согласован в чате; пользователь попросил сразу переходить к коду, без отдельной проверки спецификации.

## Трюки

| Трюк | Как выглядит | Частота (обычный характер) |
|---|---|---|
| Прыжок на экран | Прыгает «на зрителя», вырастает до ×2, прилипает к стеклу (вид спереди, видны подушечки лап), сползает, оставляя 4 полосы царапин; внизу спрыгивает. Царапины тают за 8 с, сквозь них можно кликать. | 60–120 мин |
| Стенки | Бежит к ближайшему боковому краю, лезет вверх на 30–66 % высоты, держится 3–6 с, затем спускается (60 %) или спрыгивает с кувырком (40 %). | 15–30 мин, общий таймер со «паутинкой» |
| Паутинка | Улетает за верхний край, спускается на светящейся нити в случайном месте вниз головой, раскачивается 8–14 с, поднимается, затем падает вниз и приземляется. Схватить мышью — нить рвётся. | 15–30 мин (общий таймер) |
| Кража курсора | Только если пользователь ≥ 10 с не трогал мышь и клавиатуру, курсор не выше 180 px над ртом котика. Подбегает, хватает зубами, тащит; ≤ 3 с и ≤ 300 px; движение мыши пользователем — сразу отпускает. Не в полноэкранном режиме и не при напоминании. | 120–180 мин |
| Уход | Уходит за боковой край или улетает вверх, отсутствует 1–5 мин, возвращается сбоку (может в новом наряде). Напоминание или «Позвать котика» — возвращается сразу. | 60–120 мин |

«Спокойный» характер — интервалы ×2, «игривый» — ×0,5. Каждый трюк выключается своей галочкой. Трюк начинается только из покоя. Напоминание прерывает трюк: со стены, стекла и нити котик падает и затем показывает табличку; ушедший возвращается бегом; кража курсора прекращается.

## Гардероб

Наряды: шлем космонавта (стеклянный купол, антенна-огонёк), шлем пилота (лётный шлем, очки на лбу, белый шарф), зимний комплект (вязаная шапка с помпоном, полосатый шарф). Режим в настройках: «Сам выбирает» (по умолчанию), «Без наряда», конкретный наряд. «Сам выбирает»: при запуске и затем раз в 60–120 мин котик переодевается в облачке искорок (не повторяя текущий наряд); с декабря по февраль зимний комплект выпадает с вероятностью 60 %, в остальное время его нет. Наряд виден во всех движениях.

## Устройство

- Core: `TrickSchedule`, `OutfitPicker`, `TrickSettings`, `OutfitMode`; `PetBrain` получает понятие поверхности (пол, стены, стекло, нить), фазы трюков, `Boost` (масштаб при прыжке), точку крепления нити, начало царапин, цель для курсора и наряд. Всё покрыто тестами.
- Арт: вид спереди для прыжка на экран, висение вниз головой, ходьба с курсором, облачко переодевания; по отдельному листу спрайтов на каждый наряд.
- App: поворот спрайта на стенах, масштаб при прыжке, прозрачные окна для царапин и нити, перемещение настоящего курсора с проверкой движения мыши пользователем (`SetCursorPos`, `GetLastInputInfo`), настройки наряда и трюков, пункт трея «Позвать котика». Табличка напоминания видна только когда котик действительно напоминает.
